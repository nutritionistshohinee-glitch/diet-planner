এটা একটা one-time technical setup — Patient History-তে এর জন্য আলাদা কোনো button বা click লাগবে না। একবার এখানে Connect করার পর, প্রতিটি Save Visit নিজে থেকেই background-এ আপনার নিজের Google Drive-এ save হয়ে যাবে, একদম চুপচাপ — ঠিক যেমন কোনো ওয়েবসাইটের payment/order history backend-এ save হয়।

এই device অন্য device-এ (যেমন phone-এ) করা নতুন Save Visit নিজে থেকেই কিছুক্ষণ পর পর তুলে আনবে — tab-এ ফিরে আসলে বা প্রতি ১ মিনিটে check করে। এখনই দেখতে চাইলে "🔄 Sync Now" চাপুন।

Connect না করলেও planner ও Patient History স্বাভাবিকভাবে কাজ করবে — এটা শুধু background copy-র জন্য, দৈনন্দিন কাজে কোনো প্রভাব নেই।
Patient privacy: এই setup শুধু আপনার নিজের একটি Drive file ব্যবহার করে (App শুধু নিজে যে file বানায় সেটাতেই access পায়, বাকি Drive না)। শেয়ার্ড/পাবলিক কম্পিউটারে এই setup করবেন না।
Client ID কীভাবে বানাবেন
  1. Google Cloud Console-এ যান, একটি নতুন Project তৈরি করুন।
  2. "APIs & Services → Enabled APIs" থেকে Google Drive API enable করুন।
  3. "APIs & Services → OAuth consent screen" সেট আপ করুন (External, নিজের email যোগ করুন Test user হিসেবে যদি প্রয়োজন হয়)।
  4. "APIs & Services → Credentials → Create Credentials → OAuth client ID" — Application type: Web application। Authorized JavaScript origins-এ যেখানে site host করবেন সেই link দিন (যেমন: https://yourdomain.com)।
  5. যে Client ID পাবেন, সেটা উপরে বসিয়ে Save Setup চাপুন, তারপর Connect চাপুন — এটাই শেষ, এরপর থেকে সব চুপচাপ background-এ হবে।
